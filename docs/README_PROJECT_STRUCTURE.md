StaySuite AI — Master Organization Directory
Welcome to the central Drive repository for StaySuite AI. This folder is organized following industry-standard SaaS product and engineering practices.


________________


Folder Structure Overview
📁 01_Product_and_SRS
* Software Requirements Specifications (SRS): Master requirements documents (SRS v4.0).
* Product Requirement Documents (PRDs): Module-by-module user stories and functional scope.
* Product Roadmaps & Sprints: 30-60-90 day feature delivery milestones.
* User Personas & Customer Journeys: Owner, Manager, Guest, and Staff operational flows.
📁 02_Engineering_and_Architecture
* System Architecture Diagrams: "One Brain, Three Faces" architectural blueprints.
* Database Schemas & ERDs: PostgreSQL DDL, Drift SQLite schemas, and migration notes.
* API Specifications & Contracts: OpenAPI / Swagger specs, Postman collections, WebSocket protocols.
* Sync & Hardware Protocols: Local-first sync engine rules, ESC/POS Bluetooth/USB printing specs.
📁 03_Research_and_Market_Solutions
* Hospitality & Market Research: Konkan belt homestays, coastal resort operational pain points.
* Competitor Analysis: Review of legacy PMS, Cloudbeds, and local billing software.
* OTA Integration Research: iCal parsing, Channex.io API evaluations, and Airbnb/Booking.com behaviors.
* Hardware & Device Research: Low-cost Bluetooth/USB thermal printers, on-device OCR benchmarks.
04_Codebase_and_DevOps
* Monorepo Guides & Setup: Environment setup guides (.env.example), dependency manifests.
* Docker & Deployment Configs: docker-compose.yml, Coolify setup scripts, VPS deployment guides.
* CI/CD Pipelines: GitHub Actions workflows for Android APK, Windows Desktop EXE, and FastAPI tests.
* Database Backup Strategies: Cloudflare R2 backup procedures and disaster recovery SOPs.
📁 05_UI_UX_and_Design_Assets
* Brand Guidelines & Logos: StaySuite AI branding assets, color palettes, and typography.
* Wireframes & High-Fidelity UI: Flutter POS desk screens, mobile layouts, and Next.js guest web designs.
* Physical Print Collateral: Laminated Behind-the-Door QR stickers, Reception Standee templates.
* 360° Media Specifications: Equirectangular panorama guidelines and virtual tour assets.
📁 06_Operations_Legal_and_Compliance
* Police KYC Compliance: Guidelines on guest identification, UIDAI-compliant ID masking, Form-C filing.
* Standard Operating Procedures (SOPs): Homestay owner desk guides, cook/kitchen KOT guides, cleaner QR SOPs.
* Legal & Contracts: SaaS Master Services Agreement, Terms of Service, Privacy Policy, Referral agreements.
📁 07_Business_and_Investor_Decks
* SaaS Pricing Models: One-time setup fee + AMC schedules, tier breakdowns (Standard vs. Premium).
* Pitch Decks & One-Pagers: Investor presentations, startup pitch decks, executive summaries.
* Anchor Client Case Studies: First homestay implementation notes, ROI analysis, and pilot metrics.
